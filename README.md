# 🔄 Convertidor de Unidades

Una aplicación web sencilla que permite convertir entre diferentes unidades de medida como **longitud**, **peso** y **temperatura**. Desarrollada con **Node.js**, **Express** y **EJS**, y estilizada con **Tailwind CSS** para una mejor experiencia visual.

---

## Link del proyecto

https://roadmap.sh/projects/unit-converter

## ✨ Características

- Conversión entre múltiples unidades de **longitud**, **peso** y **temperatura**.
- Interfaz intuitiva y moderna con **Tailwind CSS**.
- Lógica de conversión modular y escalable.
- Código organizado con controladores, rutas y vistas separadas.
- Sin base de datos, ideal para aprender lógica backend y formularios.

---

## 🚀 Instalación

1. Clona el repositorio:

```bash
git clone https://github.com/Grxson/UnitConverter.git
cd UnitConverter
```

2. Instalar dependencias

```bash
npm install
```

3. Iniciar el servidor

```bash
npm run dev
```

4. Abre el navegador

```bash
http://localhost:3000
```

## 🧩 Conversores disponibles

### 📏 Longitud

Convierte entre:

- Milímetro (mm)
- Centímetro (cm)
- Metro (m)
- Kilómetro (km)
- Pulgada (in)
- Pie (ft)
- Yarda (yd)
- Milla (mi)

### ⚖️ Peso

Convierte entre:

- Miligramo (mg)
- Gramo (g)
- Kilogramo (kg)
- Onza (oz)
- Libra (lb)

### 🌡️ Temperatura

Convierte entre:

- Celsius (°C)
- Fahrenheit (°F)
- Kelvin (K)

## 🛠️ Tecnologías utilizadas

- [Node](https://nodejs.org/es)
- [Express](https://expressjs.com)
- [EJS](https://ejs.co)
- [Tailwind CSS (CDN)](https://tailwindcss.com/docs/installation/play-cdn)
- [Nodemon](https://www.npmjs.com/package/nodemon)

## 🧪 Ejemplo de uso

1. Ingresa un valor.
2. Selecciona las unidades de origen y destino.
3. Haz clic en "Convertir".
4. El resultado aparecerá automáticamente debajo del formulario.
